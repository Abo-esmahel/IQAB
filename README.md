## 📌 نظرة عامة

**IQAB** مشروع ويب تعليمي/تطبيقي مبني على **Laravel**، يقدّم تجربة "متجر رقمي" كاملة: يستطيع المستخدم تصفّح وشراء **الأرقام الافتراضية** و**الخدمات الرقمية** (مثل التحقق من حسابات تليجرام)، وتُجرى جميع عمليات الدفع والشحن عبر **تليجرام باستخدام دعم العملاء** — حيث يتم توجيه المستخدم إلى الرابط المخصص للقناة (@Kh_505_p) لإكمال العملية، ولا توجد محفظة داخلية أو بوابة دفع داخل الموقع.

> الهدف المعماري: فصل "المنتج" عن "طريقة الدفع" — المعروض من منتجات (أرقام وخدمات) متاح للتصفح والشراء عبر الموقع، بينما طريقة الدفع تتم خارجياً عبر تليجرام بوساطة فريق الدعم، مما يلغي الحاجة لنظام محفظة أو بوابة دفع داخلية، ويبسط البنية ويقلل المخاطر الأمنية.

## ✨ المميزات

- 📞 **سوق أرقام افتراضية** — تصفّح، شراء، واستقبال الرسائل الواردة.
- 🤖 **خدمات رقمية** — التحقق/التبليغ/جلب معلومات حسابات تليجرام عبر مزوّد خارجي.
- 📲 **الدفع عبر تليجرام** — جميع العمليات المالية تتم بواسطة فريق الدعم على تليجرام، ولا توجد محفظة أو بوابة دفع داخلية.
- 🛡️ **لوحة تحكم للأدمن** — مستخدمون، أرقام، خدمات، تدقيق، Webhooks، وإعدادات (بدون تبويب المدفوعات/المحفظة).
- 🔌 **تكامل مرن** — التليجرام يضبط من الإعدادات دون تعديل الكود (`config/app.php` يحتوي على `telegram_contact`).
- 🔔 **إشعارات** — شراء ناجح، رسالة واردة، واقتراب انتهاء الرقم.
- 📬 **لا توجد محفظة داخلية**: جميع الرصيد والمدفوعات تتم خارج الموقع، مما يبسط البنية ويقلل المخاطر الأمنية.

## 🔐 الأمان (ممارسات الإنتاج)

تم بناء المشروع مع مراعاة معايير الأمان:

- **إيداع موثّق**: لا يُضاف أي رصيد إلا بعد تأكيد خارجي من دعم العملاء على تليجرام — لا وجود لإيداع وهمي داخل الموقع.
- **حماية Webhooks**: كل الـ webhooks محمية بتواقيع (HMAC / Secret) وترفض الأسرار غير المُهيّأة أو الوهمية (`TODO_…`).
- **سلامة المعاملات**: العمليات المالية تتم خارج الموقع عبر تليجرام، مما يلغي الحاجة لقيود `lockForUpdate` داخل قاعدة البيانات.
- **الجلسات**: مشفّرة (`SESSION_ENCRYPT`) مع كوكيز آمنة تُفعّل تلقائياً في الإنتاج.
- **تحديد المعدل**: `throttle` على المسارات الحسّاسة (كانت موجهة للإيداع سابقاً).
- **تفويض على مستوى الكائن**: `Policies` تمنع الوصول لبيانات المستخدمين الآخرين (IDOR protection).
- **وضع صيانة**: قابل للتفعيل من الإدمن ويمنع عمليات العملاء.

## 🚀 التشغيل المحلي

```bash
# 1. استنساخ المشروع
git clone https://github.com/Abo-esmahel/IQAB.git
cd IQAB

# 2. تثبيت الاعتماديات
composer install

# 3. إعداد البيئة
cp .env.example .env
php artisan key:generate

# 4. قاعدة البيانات والبيانات الأولية
php artisan migrate --seed

# 5. تشغيل الخادم
php artisan serve
```

افتح `http://localhost:8000`.

## ⚙️ الإعداد للإنتاج

في ملف `.env`:

```dotenv
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=...
DB_DATABASE=...
DB_USERNAME=...
DB_PASSWORD=...

MAIL_MAILER=smtp
MAIL_HOST=...
MAIL_USERNAME=...
MAIL_PASSWORD=...

SESSION_SECURE_COOKIE=true
QUEUE_CONNECTION=database
```

ومن لوحة الإدمن `/admin/settings` أدخل بيانات الربط:

- **التليجرام**: `api_url`، `api_token`، `bot_token`، `webhook_secret`
- **ملف الاتصال**: `telegram_contact` في `config/app.php` (= `https://t.me/Kh_505_p`)

اربط الـ webhooks لدى المزوّدين:

| الخدمة | الرابط |
|--------|-------|
| مزوّد الأرقام | `https://your-domain.com/api/webhooks/phone/messages` |
| التليجرام | `https://your-domain.com/api/webhooks/telegram` |

*(ملاحظة: تم إزالة تبويب بوابة الدفع والدفعات من لوحة الإعدادات، حيث لم تعد موجودة).*

## 💼 المهارات التقنية المكتسبة (Portfolio)

هذا المشروع يجسّد المهارات التالية ضمن بيئة عمل واقعية:

- **تطوير Full-Stack بـ Laravel** (Routing, Controllers, Models, Migrations, Seeders).
- **تصميم أنظمة دفع خارجية** مع التكامل مع تليجرام عبر API — إلغاء نظام المحفظة الداخلية والتركيز على طرق الدفع الخارجية.
- **هندسة التكامل الخارجي** (Provider/Adapter pattern) مع قابلية الضبط من لوحة التحكم.
- **كتابة اختبارات آلية** (PHPUnit) تغطي السيناريوهات الحرمة والأمنية.
- **مراجعة كود أمنية** وتصحيح ثغرات منطقية (إلغاء نظام المحفظة، التحول للدفع عبر تليجرام).
- **هندسة إعادة設計 (Refactoring)** لإزالة مراجعات المحفظة والدفع من whole codebase.
